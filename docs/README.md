## 简述

Matrix是一个Minecraft的一个游戏性扩展Mod，旨在将各种创意和有意思的东西编织在一起，就像一个矩阵，能带来独特的游戏体验。

## 游戏版本及模组加载器支持情况

Matrix目前以Minecraft 1.21, Fabric 0.102.0为基础开发。在支持的版本上运行Mod可以获得最佳兼容性。其他版本可能可以正常运行，但不作保证。
