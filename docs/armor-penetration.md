# 护甲穿透

## 属性

| 属性     | 值                         |
| ------ | ------------------------- |
| 基础法力消耗 | 30                        |
| 引导时间   | 60游戏刻/3秒                  |
| 法术类型   | 战斗类型法术                    |
| 附魔ID   | matrix:armor\_penetration |

## 描述

* 移除目标40%的护甲和韧性，持续10秒。
* 无法追踪。

## 行为

* 护甲和韧性减少的值基于目标现有的护甲和韧性计算。

## 可用状态

* 如果目标免疫药水效果，则可用状态为“目标免疫”
