# 生命偷取

## 属性

| 属性     | 值                    |
| ------ | -------------------- |
| 基础法力消耗 | 8                    |
| 引导时间   | 20游戏刻/1秒             |
| 法术类型   | 终极类型法术               |
| 附魔ID   | matrix:health\_steal |

## 描述

* 将目标的50%最大生命值转换为生命吸收，该技能无法将生命吸收数额提升至你最大生命值的100%以上。
* 转换值的50%用于恢复生命值，饥饿值和饱和度。
* 无法追踪。

## 行为

* 如果技能生效时玩家不在线，则无效。

## 可用状态

* 始终可用
