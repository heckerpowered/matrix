# 力大砖飞

## 属性

| 属性     | 值                   |
| ------ | ------------------- |
| 基础法力消耗 | 45                  |
| 引导时间   | 40游戏刻/2秒            |
| 法术类型   | 战斗类型法术              |
| 附魔ID   | matrix:brute\_force |

## 描述

* 使目标进入危险状态，持续5秒。
* 受危险状态影响的生物受到的伤害增加40%。此效果每一等级额外增加40%受到的伤害，但此技能不会提升危险状态的等级。
* 对已受到影响的目标使用会将持续时间提升至8秒。
* 无法追踪。

## 可用状态

* 如果目标免疫药水效果，则可用状态为“目标免疫”
