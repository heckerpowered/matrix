# 概览

Matrix模组中的法术能为玩家解锁远程施法的能力。法术没有冷却时间，只要有法力就能施法。

成为巫师后可以解锁远程施法的能力。

## 成为巫师

目前，成为巫师的唯一方式是佩戴巫师头盔。但随着模组更新，可能会出现更多的方式成为巫师，不需要巫师头盔也能够施法。

## 魔法

魔法也可称作“法术”，或“技能”，它们以附魔的形式附着于头盔上。每个魔法都有相对应的附魔，在头盔上附上技能相对应的附魔，即可为头盔解锁对应的技能，佩戴头盔可以使用头盔已解锁的所有技能。

## 法力

法力是使用魔法所需要消耗的资源。法力储存于玩家内部，但玩家可拥有的最大法力值由头盔决定。脱下头盔会立即清除已有的法力。

在没有任何额外加成的情况下，每20游戏刻（1秒）恢复1单位法力。

## 使用魔法

佩戴巫师头盔后按下TAB以打开扫描界面。单人模式下打开扫描界面会将时间减慢99%。不论单人还是多人，扫描界面打开时，会自动选定准星附近最近的一个可施法目标，同时准星会吸附到目标身上。

通过鼠标滚轮或上下键选定魔法后，按下施法键（默认为F）使用法术。

魔法的消耗，可用状态，当前法力，目标信息和法术介绍等会显示在扫描界中。

## 法术抗性

部分敌对怪物天生拥有法术抗性。法术抗性只影响Matrix模组中的魔法，敌人的法术抗性越高，表明敌人越不容易受到法术影响，使用法术所需要的法力越高，引导法术所需要的时间也越长。相反地，如果敌人的法术抗性越低（如小于0），那么表明敌人更易受到法术影响，使用法术所需要的法力越低，引导法术所需要的时间也越短。

使用法术所需要的法力不会低于1。受法术抗性影响增加的法力消耗和引导时间没有上限。

### 法术抗性修正

法术抗性修正是根据游戏难度动态地调整敌对生物的法术抗性。

只有敌对生物会受到法术抗性修正影响，例如玩家不受此机制影响。

## 追踪和法术对抗

非隐蔽类型的法术伤害具有来源，可以追踪到施法者。隐蔽类型法术造成的伤害不具有来源，因此无法被追踪。

非隐蔽类型在目标身上开始引导时，若目标具有法术对抗能力，则可以立即开始追踪。追踪会暴露施法者的位置，并能够进行反击。
