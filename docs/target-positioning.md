# 目标定位

> 唯一的信息类技能，相较于光灵箭它获取信息的代价几乎低到可以忽略不计，是不是太超模了？

## 属性

| 属性     | 值                          |
| ------ | -------------------------- |
| 基础法力消耗 | 4                          |
| 引导时间   | 20游戏刻/1秒                   |
| 法术类型   | 隐蔽类型法术                     |
| 附魔ID   | matrix:target\_positioning |

## 描述

* 高亮目标及其周围24米内的其他目标（不包括施法者），持续10秒。
* 无法追踪。

## 行为

* 高亮通过为目标添加一个持续10秒的，等级为0的发光效果实现。因此高亮效果向所有人可见，且可被牛奶清除。
