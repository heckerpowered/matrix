# 法力过载

## 属性

| 属性     | 值                     |
| ------ | --------------------- |
| 基础法力消耗 | 4                     |
| 引导时间   | 6游戏刻/0.3秒             |
| 法术类型   | 控制类型法术                |
| 附魔ID   | matrix:mana\_overload |

## 描述

* 最多可以叠加8次，持续10秒，叠加时重置持续时间。
* 对受到影响的敌人造成的伤害+15%。
* 受影响的目标无法造成魔法伤害，禁用并立即禁用目标的法术能力
  * 禁用末影人的传送能力。
  * 坚守者无法再引导音波尖啸。
  * 禁用唤魔者和幻术师的所有法术。
  * 禁用嘎枝免疫伤害的能力。
  * 禁用守卫者激光攻击及远古守卫者赋予玩家挖掘疲劳效果的能力。
  * 使女巫无法丢出药水。&#x20;
* 叠加2层时移除并屏蔽目标身上的有益效果。
* 叠加3层时目标受到的伤害增加，数额相当于其当前生命值的8%。
* 叠加到最大时，对目标造成其100%当前生命值的法术伤害，效果结束前无法再叠加。
* 无法追踪。

## 行为

* 禁用法术能力会立刻中断正在使用的法术，例如坚守者正在引导的音波尖啸。

## 可用状态

* 如果目标免疫药水效果，或“法力过载”效果等级大于等于7，可用状态为“目标免疫”
