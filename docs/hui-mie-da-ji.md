# 毁灭打击

## 属性

| 属性     | 值                       |
| ------ | ----------------------- |
| 基础法力消耗 | 16                      |
| 引导时间   | 60游戏刻/3秒                |
| 法术类型   | 战斗类型法术                  |
| 附魔ID   | matrix:decisive\_strike |

## 描述

* 对目标造成6点伤害，附带额外伤害，数额相当于玩家攻击力100%以及目标最大生命值的14%。
* 基于已使用的法力值百分比，每使用1%法力增加4%伤害。（至多400）
* 使用该法术消灭一名敌人后，-2法术占用，持续15秒。可以叠加3次。
* 血之契约激活时，伤害增加100%。使用该法术消灭一名敌人后，血之契约的持续时间增加3秒。
* 可被追踪。

## 行为

{% hint style="info" %}
此法术正在实现中，可能与当前行为不同
{% endhint %}

伤害计算公式:

$$
(6 + ATK + HP_{max}*0.14) * (1 + M*0.04 + B)
$$

其中, $$ATK$$是玩家攻击力, $$HP_{max}$$是目标最大生命值。 $$M$$是已使用的法力值百分比。 $$B$$是血之契约状态，激活时为1，否则为0。



毁灭打击造成法术伤害。

## 可用状态

* 始终可用
