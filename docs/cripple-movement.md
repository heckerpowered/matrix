# 阻碍移动

## 属性

| 属性     | 值                        |
| ------ | ------------------------ |
| 基础法力消耗 | 6                        |
| 引导时间   | 6游戏刻/0.3秒                |
| 法术类型   | 控制类型法术                   |
| 附魔ID   | matrix:cripple\_movement |

## 描述

* 禁用目标的移动能力，传送和闪避能力，持续10秒。
* 对抗玩家时，消耗提升3倍，持续时间降低至3秒。
* 无法追踪。

## 行为

* 尽管末影人免疫弹射物和药水伤害，但受阻碍移动影响时，禁用末影人免疫此类伤害的能力。

## 可用状态

* 如果目标免疫药水效果，则可用状态为“目标免疫”
