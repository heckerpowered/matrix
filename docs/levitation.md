# 装逼让你飞起来

## 属性

| 属性     | 值                 |
| ------ | ----------------- |
| 基础法力消耗 | 30                |
| 引导时间   | 40游戏刻/2秒          |
| 法术类型   | 战斗类型法术            |
| 附魔ID   | matrix:levitation |

## 描述

* 使目标进入漂浮状态，持续5秒。
* 可叠加，叠加时提升效果等级，并将持续时间提升至8秒，没有上限。
* 无法追踪。

## 可用状态

* 如果目标免疫药水效果，则可用状态为“目标免疫”
