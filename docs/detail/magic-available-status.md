# 法术可用状态

### 可用 (AVAILABLE)

当前法术可用，这种状态不会出现在法术状态提示栏中。

### 可用法力不足 (AVAILABLE\_MANA\_NOT\_ENOUGH)

当前的法力值小于选定的法术所需的法力值。

### 目标免疫 (TARGET\_IMMUNE)

目标免疫选定的法术。例如，僵尸猪人免疫火焰，那么无法以僵尸猪人为目标使用点燃。

目标定位会在目标及其周围的生物上施加发光效果，但即使选定的目标免疫发光效果，也可使用目标定位。

### 不可用 (UNAVAILABLE)

法术因未知原因不可用。

此状态尚未被使用。

### 队列已满 (CHANNEL\_QUEUE\_FULL)

目标已有正在引导的法术，且未解锁法术队列，或是你在目标身上堆叠的法术数量已占满法术队列。

### 队列已锁定 (CHANNEL\_QUEUE\_LOCKED)

你在目标身上的法术队列已锁定，在队列解锁前无法再对其引导法术。

常见的例子是巫师头盔附魔了队列精通，队列被排满时会被锁定，直到所有法术引导完毕。

### 目标缺失 (TARGET\_MISSING)

选定的法术不能进行无目标释法，此类法术不会出现在法术状态提示栏中。

### 幽匿催发已经激活 (SCULK\_CATALYST\_IS\_ALREADY\_ACTIVE)

只有幽匿催发会有此类状态，幽匿催发在上传时被激活，同一时刻可以有多个幽匿催发引导，但幽匿催发激活后不可再引导新的幽匿催发。
