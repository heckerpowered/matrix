# 无形的大手

## 属性

| 属性     | 值              |
| ------ | -------------- |
| 基础法力消耗 | 20             |
| 引导时间   | 20游戏刻/1秒       |
| 法术类型   | 战斗类型法术         |
| 附魔ID   | matrix:attract |

## 描述

* 在目标位置创建一个持续3秒的无形的大手，持续将附近6米内的实体牵引至其位置。（不包括施法者）
* 无法追踪。

## 可用状态

* 如果目标免疫药水效果，则可用状态为“目标免疫”
