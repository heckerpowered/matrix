# 连带传染

> 一开始设计为传染不需要消耗法力，发现太过超模。但需要法力又没什么用了。

## 属性

| 属性     | 值             |
| ------ | ------------- |
| 基础法力消耗 | 9             |
| 引导时间   | 9游戏刻/0.45秒    |
| 法术类型   | 战斗类型法术        |
| 附魔ID   | matrix:spread |

## 描述

* 生效时，将引导队列中排在此魔法后的法术散布到24米内的其他可施法目标上（不包括施法者）。
* 散布时自动消耗法力。
* 这个魔法本身不能被散布。

## 行为

* 散布需要消耗法力，且行为如同玩家对目标释放一次被散布的魔法。 散布可能会失败，例如法力不足，或目标免疫对应的魔法。
