# 绝命毒师

> 可能这个技能的主要作用是产生爆炸而非单纯的中毒。

## 属性

| 属性     | 值                    |
| ------ | -------------------- |
| 基础法力消耗 | 9                    |
| 引导时间   | 40游戏刻/2秒             |
| 法术类型   | 战斗类型法术               |
| 附魔ID   | matrix:breaking\_bad |

## 描述

* 使目标中毒5秒，造成持续伤害。
* 使目标失明5秒。
* 自动散布到8米内的最近的4个目标上。
* 如果目标着火，则在目标位置产生一次威力为4的爆炸。
* 这个技能无法被二次散布。

## 行为

* 散布会找到8米内的4个互相距离最近的目标，如果散布失败，则会继续寻找，直到成功散布4或初始目标8米内不存在可施法目标。

## 可用状态

* 如果目标免疫中毒或致盲，则可用状态为“目标免疫”
