# 传送

## 属性

| 属性     | 值               |
| ------ | --------------- |
| 基础法力消耗 | 15              |
| 引导时间   | 5游戏刻/0.25秒      |
| 法术类型   | 战斗类型法术          |
| 附魔ID   | matrix:teleport |

## 描述

* 传送到目标位置
* 自动攻击目标位置处半径3米内的生物（包括目标）。每次攻击前自动蓄力至最大。

## 行为

* 攻击时会生成“Crit”和Enchanted Hit”特效，并挥动手臂。
