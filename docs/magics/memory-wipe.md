# 记忆擦除

## 属性

| 属性     | 值                    |
| ------ | -------------------- |
| 基础法力消耗 | 9                    |
| 引导时间   | 40游戏刻/2秒             |
| 法术类型   | 隐蔽类型法术               |
| 附魔ID   | matrix:memory\_erase |

## 描述

* 使目标解除锁定其正在锁定的目标。
* 排在记忆擦除后的法术无法被追踪。
* 如果目标是村民，迫使目标忘记其对你的负面记忆。
* 无法追踪。

## 行为

* 排在记忆擦除后的法术造成伤害时，其伤害来源会被抹掉。这会导致无法识别伤害是否是你造成的，一些只有你才能触发的效果就无法生效。
* 村民的负面记忆会导致商品价格上涨，一般发生在你攻击村民，或击杀其他村民被目睹。使用记忆擦除将强迫村民忘记这些记忆，但不会清除村民对你的有益的记忆。这一机制在玩家不在线时可能无法生效。
* 如果目标是怪物，清除其的目标，停用其所有的目标选择器。
* 对于所有可“愤怒”的实体，迫使其退出愤怒状态。

## 可用状态

* 始终可用
