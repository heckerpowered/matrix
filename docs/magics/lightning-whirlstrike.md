# 闪电旋风劈

## 属性

| 属性     | 值                      |
| ------ | ---------------------- |
| 基础法力消耗 | 15                     |
| 引导时间   | 20游戏刻/1秒               |
| 法术类型   | 战斗类型法术                 |
| 附魔ID   | matrix:lightning\_bolt |

## 描述

* 在目标位置召唤闪电，闪电的颜色可能是：红色，橙色，黄色，绿色，青色，蓝色，紫色，白色，无色。
* 无色闪电的抽取概率是0.6%，其他所有颜色抽取概率均分。
* 由玩家引导的闪电与自然闪电有不同的行为，例如不会充能苦力怕，伤害不随难度变化，也不会触发成就。
* &#x20;连续释放法力消耗-20%，可叠加，至多至80%。

## 颜色闪电

只有白色和红色闪电会造成火焰（不影响使命中目标着火）。

## 行为

* 召唤的闪电可以命中施法者。
* 生效时在\[0, 1000]随机地抽取一个数字，如果小于6，那么闪电类型为无色闪电。
* 如果大于等于6，那么在所有闪电类型中随机抽取。如果随机抽取到无色闪电，那么再次抽取。

## 法力消耗

* 默认法力消耗为15。
* 目标身上每有1个正在引导或正在排队的“闪电旋风劈”，法力消耗减少20%，至多80%。
