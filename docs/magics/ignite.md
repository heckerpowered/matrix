# 点燃

> 点燃魔法不仅能让目标着火，还能为目标施加多种负面效果，甚至是造成爆炸。

## 属性

| 属性     | 值             |
| ------ | ------------- |
| 基础法力消耗 | 9             |
| 引导时间   | 9游戏刻/0.45秒    |
| 法术类型   | 战斗类型法术        |
| 附魔ID   | matrix:ignite |

## 描述

* 点燃目标持续5秒，造成持续伤害。
* 如果目标已受到点燃效果的影响，则持续时间提升至至多8秒。
* 攻击受到点燃影响的目标将导致持续时间延长0.5秒。
* 融化目标的护甲，减少目标40%的护甲和韧性。
* 受点燃效果影响的目标受到的伤害增加20%。
* 如果目标中毒，则在目标位置产生一次威力为4的爆炸。

## 行为

* 点燃魔法包括两部分：使目标着火及施加“点燃”效果。
* ”受到点燃效果影响“的判定方式是检查目标身上的”点燃“效果，而非是否着火。
* 法术产生的爆炸不会破坏方块，也不会产生火焰。

## 可用状态

* 如果目标免疫火焰，则可用状态为“目标免疫”
