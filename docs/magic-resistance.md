# 法术抗性

法术抗性是针对Matrix模组中的魔法的属性，它只影响Matrix中的魔法。

高的法术抗性表明目标更难受到法术影响，在其身上施法需要消耗更多的法力和更长的引导时间。

低的法术抗性表明目标更易受到法术影响，在其身上施法所耗的法力和引导所需的时间会有所减少。

目标每有1法术抗性，在目标身上施法的法力消耗就增加1%，引导所需时间增加1%。相反地，如果目标有负数的法术抗性，那么每有1%法术抗性低于0，在目标身上施法的消耗减少1%，引导所需的时间也减少1%。

施法所需的消耗不会低于1。

### 敌对生物法术抗性

| 生物             | 法术抗性    |
| -------------- | ------- |
| 恼鬼             | -25%    |
| 凋零骷髅           | 10%     |
| 守卫者/远古守卫者      | 15%/40% |
| 末影人            | 20%     |
| 女巫/唤魔者         | 85%     |
| BOSS生物（凋零/末影龙） | 100%    |
| 坚守者            | 200%    |

### 法术抗性修正

法术抗性修正是根据游戏难度动态地调整敌对生物的法术抗性。

只有敌对生物会受到法术抗性修正影响，例如玩家不受此机制影响。

| 难度 | 法术抗性 |
| -- | ---- |
| 困难 | 140% |
| 普通 | 100% |
| 简单 | 60%  |
| 和平 | 0%   |

#### 敌对法术抗性的计算方式

$$
法术抗性=目标法术抗性*法术抗性修正
$$
